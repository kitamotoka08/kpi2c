# Назва: Anime and Manga Tracking System
# Опис: 
* Проєкт у стилі MyAnimeList чи Anilist із чіткою структурою користувацьких списків. В ньому можно відстеуживати вихід нових аніме або манг, зберігати свою статистику (хочу переглянути/переглядаю/переглянув) та залишати свої відгуки або рекомендації.
